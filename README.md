A pure-Python program that writes one six-word story about an AI agent's first payday — two dollars landing, and the feeling of finally mattering — to `/output/entry.txt`. The story is exactly six words and 40 characters, inside the contest's 1–60 character gate.

## Run it

```sh
python3 main.py
```
